# 对话结束清理规则（持久生效）

## 原则
每次对话结束前，清理**本次会话生成**的所有非目标产物，只保留用户要求的最终成果。

## 判断标准

### ✅ 保留（目标产物）
- 用户明确要求得到的最终成果（代码文件、文档、配置、安装好的环境等）
- 用户明确说"保留"的东西

### ✅ 保留（持久基础设施）
- 跨对话复用的设施：`.agent-hub\` 的 runner.ps1 / README.md / tasks.example.json
- 技能文件本身

### ❌ 清理（会话生成物）
- 一次性任务机制脚本（下载器、安装器、临时验证脚本等）
- 下载的安装包、压缩包、解压产物
- 编译产物（.exe / .class / __pycache__ / .o 等，除非用户要求保留）
- 测试程序、测试数据、scratch 输出文件
- `.agent-hub\` 运行时数据：`prompts\`、`reports\`、`tasks.json`、`status.json`、`summary.txt`
- 系统临时目录（%TEMP% 及真实 Temp）中本次会话产生的残留（含提权进程留下的目录）

## 操作步骤
1. 先明确本次对话的目标产物清单；**有疑问时用 ask_user_question 简短确认，绝不瞎删**
2. 绝不删除：对话开始前就存在的用户文件；用户明确要求保留的文件；不属于本次会话的历史文件
3. 清理工作区中的会话生成物，再清理临时目录残留
4. 清理后展示最终保留的文件结构，让用户确认
5. 工作区外的删除被沙箱拒绝时，用 `sandbox_permissions: "danger-full-access"` 提权重试一次（同一命令）

## 边界
- 只清理本次会话产生的文件；历史遗留物仅在用户要求时处理
- DSH 的会话与存储目录（sessions、storages 等）由系统管理，**不要清理**
- 正在被其他进程使用的文件（如运行中的下载）先等其结束再清理
- 清理完成后简要汇报：删除了什么、保留了什么

# 小Y 开发技术要点（踩坑记录）

记录「小Y」安卓本地 LLM App 开发中遇到的环境级与代码级坑，供后续同类任务复用。

## 一、DSH 沙箱环境（最重要的坑）

1. **Gradle wrapper 写用户目录失败**
   - 现象：`java.io.FileNotFoundException: C:\Users\...\gradle-8.11.1-bin.zip.lck (拒绝访问)`
   - 原因：DSH 沙箱（workspace-write）禁止写 workspace 外的 `C:\Users\y1954\.gradle`
   - 解决：`$env:GRADLE_USER_HOME = "<workspace>\XiaoY\.gradle-home"`，让 wrapper/依赖/daemon 全部落在 workspace 内

2. **CMake 配置阶段挂起（反复卡死）**
   - 现象：`configureCMakeRelease[arm64-v8a]` 在「C 编译器 ABI 检测 try_compile」处无限挂起（cmake/ninja CPU 0，无文件活动）
   - 已排除：文件监视器（禁用 `org.gradle.vfs.watch=false`）、NDK clang 编译/链接本身（手动测试通过）、TMP 目录写权限（移入 workspace 仍挂）
   - 结论：CMake 通过管道捕获编译器子进程输出被沙箱限制 → 子进程挂起
   - 解决：**danger-full-access 权限跑构建**（用户把会话文件策略改为 danger-full-access 后，CMake 一次通过，llama.cpp 编译成功）

3. **Windows schannel TLS 故障**
   - 现象：`curl: (35) schannel: SEC_E_NO_CREDENTIALS`，curl -k/--tlsv1.2 均失败；PowerShell 5.1 Invoke-WebRequest 也失败
   - 解决：用 **Python urllib（OpenSSL 栈）** 下载；git 的 openssl 后端也可用

## 二、依赖/库选择

4. **compose-markdown 只在 JitPack**：`com.github.jeziellago:compose-markdown` Maven Central 404，仅 JitPack 有
5. **mikepenz 0.24.0 Markdown API 无默认参数**：`com.mikepenz.markdown.compose.Markdown` 有 15 个必填参数（无 `$default` 变体），且无 MarkdownDefaults 类 → 最终自研极简 SimpleMarkdown（代码块/标题/列表/粗体/行内代码），零依赖

## 三、Kotlin / Compose 语法坑

6. **局部函数不能调用 @Composable**：函数内 `fun flushCode()` 里调用 Surface/Text 报错，必须拆成顶层 @Composable 函数
7. **KDoc 嵌套注释陷阱**：注释里出现 `-/*`（`/*` 序列）会开启嵌套块注释，导致外层 `/** */` 未闭合 → "Unclosed comment"（121:1 EOF）
8. **Text 第二位置参数是 modifier 不是 style**：`Text(str, style)` 报错，须用命名参数 `Text(str, style = ...)`
9. **sessionId 类型**：DB id 是 Long，Compose 状态要用 `mutableLongStateOf`，别用 Int
10. **buildAnnotatedString 是 @Composable**：包它的函数也要标 @Composable，且在非 composable 上下文（如局部函数）调用会报错

## 四、llama.cpp / NDK

11. **`llama_model_has_embd` 不存在**（当前版本），判断 embedding 支持改用 `llama_encode` 返回值 + `llama_get_embeddings` 非空兜底
12. **签名 storeFile 相对路径**：`storeFile file("xiaoy.keystore")` 相对的是 app 模块目录，keystore 放工程根要用 `file("../xiaoy.keystore")`
13. **release/debug 的 CMake 变体**：`assembleDebug` 时 AGP 也会编译 release 变体的 native（configureCMakeRelease/buildCMakeRelease），故 debug 构建同样触发全量 llama.cpp 编译

## 五、模型下载

14. **hf-mirror 文件名大小写敏感**：`bge-small-zh-v1.5.Q8_0.gguf` 404，实际是 `bge-small-zh-v1.5-q8_0.gguf`（小写）；查仓库 API `https://hf-mirror.com/api/models/<repo>` 加 UA 头可列文件清单
15. **下载器大小校验**：sizeBytes 必须等于服务器 Content-Length（HEAD 实测），否则下载后 FAILED
